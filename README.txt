Connect Studio — офлайн-версия 0.5

1. Распакуйте ZIP в отдельную папку.
2. Откройте index.html в Chrome, Edge или Firefox двойным щелчком.
3. Работайте со схемой, вкладкой «Ошибки», импортом JSON и экспортом YAML.

Установка Python, Node.js, Docker и доступ к интернету не требуются.
Ссылки на документацию открывают внешний сайт и без интернета не работают.
Если кнопка копирования недоступна, используйте «Экспорт YAML».

Проект с сайта автоматически сюда не переносится:
на сайте нажмите «Скачать проект», затем в локальной версии «Открыть проект».
Для надёжного сохранения регулярно скачивайте JSON через «Скачать проект»:
автосохранение для file:// зависит от браузера и расположения папки.

Этот инструмент создаёт конфигурации. Он не запускает Redpanda Connect,
не читает Kafka и не подключается к Dragonfly или Cassandra.
Запуск полученного YAML выполняется отдельно в вашей инфраструктуре.
Целевая версия конфигураций: Redpanda Connect 4.68.x, обычный режим try/catch.
Перед запуском проверяйте YAML: rpk connect lint connect.yaml.

Исходники доступны: index.html, style.css, core.js (генератор), app.js (интерфейс).

Маршрутизация (версия 0.5):
- В каталоге нажмите «Маршрутизация» или откройте вкладку «Ветки».
- По условию: первое совпадение; без совпадений — общий выход «Остальные события».
- Во все ветки: копия каждому; общий выход не используется.
- В ветке нажмите «Добавлять блоки сюда», затем выбирайте компоненты в каталоге.
- Условия по топику: @kafka_topic == "orders_web".
- В Kafka-источнике укажите все нужные топики через запятую.
- Правила вкладки «Ошибки» применяются к общей цепочке и каждой ветке.
- Медленный выход в режиме копирования может задерживать весь поток.
- Поддерживается один уровень ветвления. Проекты 0.3 импортируются.

ClickHouse (версия 0.5):
Выберите ClickHouse в разделе выходов каталога, в общей цепочке или ветке.
Задайте DSN через ${CLICKHOUSE_DSN}, таблицу, колонки и Bloblang-массив значений.
Пример DSN: clickhouse://default@localhost:9000/default
Для TLS используйте параметр secure=true в DSN.
Таблица должна существовать. Порядок массива значений совпадает с порядком колонок.
Можно настроить размер пакета, время его ожидания и параллельные записи.
Ошибки записи ClickHouse не перехватываются DLQ для ошибок процессоров.
